## 📖 项目简介

闲的没事写着玩的。
《Hong Kong Stock Trading Handbook》是一份面向港股投资者的系统性学习与实战资料，内容从零基础交易规则开始，逐步延伸至选股、估值、资金面、仓位管理、风险控制、公司行动、卖空、ETF、衍生工具、组合管理与交易系统建设。

本手册的目标不是提供具体股票推荐，也不是预测市场短期涨跌，而是建立一套完整、可核验、可执行、可复盘的港股交易知识体系。

## 🧮 手册特色

本手册包含：

- 80个正文章节
- 15个贯穿式计算案例
- 13项附录
- 官方规则与资料索引
- 交易日志模板
- 一页研究卡模板
- 催化剂日历
- 月度策略复盘模板
- 风险红线清单
- 未来制度更新清单

对于制度性内容，手册区分：

- 【现行规则】
- 【已公布待实施】
- 【咨询中 / 拟议方案】

同时区分：

- 【制度规则】
- 【交易经验】
- 【示例参数】

以避免将市场经验、个人参数与正式监管制度混为一谈。
